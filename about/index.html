How I build

Honest answer: with a lot of help from AI.

I build with AI-assisted development, mostly with Claude Code. I decide what to make, write a detailed spec, and then work through it with Claude: I review every change, test it on real hardware, and only release when it feels right. It lets one student ship polished apps that would otherwise need a team.

  1. 1IdeaSomething I want for myself or my friends.
  2. 2Detailed specEvery screen, rule and edge case written down first.
  3. 3BuildPair-programming with Claude Code, one feature at a time.
  4. 4TestUnit tests, real-device runs and a lot of clicking around.
  5. 5ReleaseA signed build, release notes and automatic updates.
